# Data

## The two databases

| File | Role | Written by |
|---|---|---|
| `prospects.db` | **Live.** Current-season stats appended nightly. | `deploy/daily_data.py` |
| `prospects_snapshot.db` | **Modeling.** A weekly clone of the live DB so a long training run reads a stable file. | `deploy/weekly_score.py` copies `prospects.db` over it |

The weekly copy is the one supported bridge between them. The snapshot name is
historical — it is **not** a frozen snapshot; it is refreshed every weekly run.
`config.live_db()` / `config.model_db()` resolve them (override via the
`PROSPECT_DB` / `PROSPECT_MODEL_DB` environment variables).

Key tables: `prospects`, `season_stats`, `career_outcomes`, `prospect_rankings`.

## Sources (`prospects/data/sources/`)

One module per external source:

- `milb.py` — MiLB batting/pitching by level (MLB Stats API). The nightly pull.
- `pybaseball.py` — MLB career, draft, Lahman seasons.
- `ncaa.py`, `college.py` — college stats.
- `bwar.py`, `season_war.py` — Baseball-Reference WAR.
- `baseballcube.py`, `baseballcube_xref.py`, `baseballcube_integrate.py` —
  historical org rankings (inputs in `reference/baseballcube/`).
- `outcomes.py`, `mlb_draft.py` — career outcomes and draft cache.

`prospects/data/pull.py` orchestrates a bulk historical pull
(`python -m prospects.data.pull --phase all`).

## Backfills (`prospects/data/backfills/`)

Hand-run, one-shot repair scripts — birthdates, IFA/biometric fields, org
assignment, dedup, draft-conflation fixes, Lahman MLB seasons, season metadata.
Run individually as needed; several accept `--db` to target either database.

## Reference inputs (`reference/`)

Hand-curated, checked in:

- `prices/prices_bowman_chrome_auto_v13.csv` — eBay price reference for the buy list.
- `baseballcube/` — player xref + org rankings.
- `fangraphs_board/` — the FanGraphs scouting-grade pipeline. The model reads
  `scouting_grades_pointintime.csv`; the `raw/` and `parsed/` scrape workspace
  (~85 MB) is git-ignored and regenerated by the `tools/` scrapers
  (`scrape_fangraphs_board.py` → `build_fg_crosswalk.py` → `build_scouting_grades.py`).
- `milb_baselines.json` — league medians by level, for level-adjusted features.

## Scouting grades

`features/grades.py` loads `config.SCOUTING_GRADES`
(`reference/fangraphs_board/scouting_grades_pointintime.csv`) and appends
no-look-ahead grade features to the panel. Missing → NaN (HistGBT-safe). Set
`SCOUTING_GRADES_OFF=1` to disable them for an A/B run.
